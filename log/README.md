# DSA Error Log

This folder contains the mistakes I make while solving DSA
problems and the lessons I learn from them.

## Purpose

- Understand why I made the mistake
- Identify the pattern behind the problem
- Avoid repeating the same mistake
- Improve problem-solving instead of only memorizing solutions

## Topics

- Hashing
- Arrays
- Trees
- Binary Search
- Two Pointers
- Sliding Window
